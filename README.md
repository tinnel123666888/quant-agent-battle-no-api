## Quick Start

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Set your CodeBuddy API key

```bash
# PowerShell
$env:CODEBUDDY_API_KEY="your_codebuddy_key"
```

3. Run scheduler

```bash
python scripts/run_scheduler.py
```
